# Локальный стенд формы заявки

Позволяет открыть форму в браузере без Bitrix, 1С и DaData.

```bash
npm install
npm run stand:init     # создаёт js/vue/registration-course/plugins/api.js из mock-api.js
npm run dev            # http://localhost:5173
```

## Как это устроено

- `index.html` (в корне) — точка входа стенда. Базовые стили шаблона Bitrix (`.form-control`,
  `.btn`, шрифты, сетка) подтягиваются с боевого сайта, потому что самого шаблона в
  репозитории нет.
- `mock-api.js` — заглушка вместо `plugins/api.js`. Отдаёт синтетические ответы 1С и DaData
  с задержкой, отправку заявки печатает в консоль браузера.
- `init.mjs` — копирует заглушку в `plugins/api.js`, **только если файла ещё нет**.
  Существующий файл не перезаписывается никогда: на серверах там боевые креды.

`plugins/api.js` в `.gitignore` и не попадает в git ни при каких обстоятельствах.

## Тестовые данные заглушки

| Что | Значение |
|---|---|
| СНИЛС с полными данными | `92703662611` |
| ИНН организации | `2311128737` |
| Код подразделения | `770-001` |
| БИК банка | `044525225` |
| Программы | PROG-01 … PROG-04 |

Нужны другие данные — правь `mock-api.js`, а не сгенерированный `plugins/api.js`.

## Чего стенд не проверяет

Реальную интеграцию с 1С и DaData: форматы ответов, ошибки, таймауты, неполные данные из
боевой базы. Это проверяется только на `dev.likey.su`.
